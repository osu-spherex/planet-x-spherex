# Статик кубууд (L1)

`python -m data.cube <объект> <детектор>` үүсгэнэ (жишээ нь `python -m data.cube barnard SPHEREx-D1`).
Эх өгөгдөл: IRSA-ийн SPHEREx Level 2 cutout-ууд, урьдчилан татсан кэшээс (git-д ороогүй) — куб нь **кэшээс** гарсан
жинхэнэ өгөгдөл, `cube.json`-ийн `source.from_cache = true`.

- `data/cubes/` — 11/14-нд татсан кэшээс (`data/cache_dr1`): **DR1 + QR3 холимог**, IRSA одоо яг ингэж өгдөг.
  Frame-ийн тоог хувилбараар `source.releases`-д бичсэн (жишээ нь `{"dr1": 42, "qr3": 18}`).
- `data/cubes_qr/` — 11/10-нд татсан кэшээс (`data/cache`, QR2 + QR3): **нөөц** хувилбар, формат ижил.
  Хоёрын зөрүү (урсгал 3% орчим): `docs/DR1_VS_QR.md`.

Хавтас бүрт: `cube.json` (метадата), `cube.f32` (пикселүүд), `quicklook.png` (нүдээр шалгах зураг,
`python -m data.quicklook <объект> <детектор>`).

**Шинэчлэх (A-12):** `python -m data.refresh [объект ...]` — IRSA-ийн одоогийн жагсаалтыг кэштэй харьцуулж, дутууг татаж, энэ хавтасны
объектын бүх файлыг дахин үүсгээд юу өөрчлөгдсөнийг хэвлэнэ; `--dry-run` зөвхөн жагсаана, `--offline` кэшээс л дахин бүтээнэ.
Заавар: `docs/UPDATING.md`.

## Формат

`cube.f32`: little-endian Float32, `shape = [N, H, W]`, нэгж MJy/sr, frame бүрээс дэвсгэрийг хассан.
Талбарын хэмжээ `fov_arcmin` = 3, 6 эсвэл 10 (нуман минут) → `H = W = fov_arcmin * 20 + 1` = 61, 121, 201; пиксел үргэлж 3″.
Статик кубууд бүгд 3′ (61 × 61). **61 гэж хатуу бүү бич** — `shape`-аас ав; төв нь `((W - 1) / 2, (H - 1) / 2)`.

```js
const meta = await (await fetch(jsonUrl)).json();
const buf = await (await fetch(new URL(meta.data_url, jsonUrl))).arrayBuffer();
const data = new Float32Array(buf);
const [N, H, W] = meta.shape;
const v = data[n * H * W + y * W + x];   // frame n, row y, column x
```

**Чиглэл:** мөр `y = 0` нь хойд (north) ирмэг, багана `x = 0` нь east ирмэг. Canvas дээр дээрээс доош
шууд зурахад тэнгэрийн ердийн харагдац гарна: north дээр, east зүүн гар талд. Төв нь `(x, y) = (c, c)`, `c = (W - 1) / 2` (3′-д 30),
`center.ra / center.dec`. Пиксел 3″:

```
east offset  = (c - x) * 3″        north offset = (c - y) * 3″
```

**NaN** = хүчинтэй өгөгдөлгүй пиксел. Хоёр шалтгаантай: (1) cutout-ын гадна (булангууд, детекторын ирмэг дээр
тайрагдсан зураг); (2) SPHEREx pipeline өөрөө хүчингүй гэж тэмдэглэсэн пиксел — тод одны **ханасан гол**
(Barnard's Star, R Dra) үүнд орно, тиймээс одны голд жижиг нүх харагдана. Зурахдаа NaN-ийг тусад нь өнгөөр ялга,
нийлбэр/медиан авахдаа алгас.

`frames[i]` нь `cube.f32`-ийн i-р frame, MJD-ээр эрэмбэлэгдсэн:

| Талбар | Утга |
| --- | --- |
| `id` | IRSA-ийн файлын нэр (өргөтгөлгүй) |
| `band` | `D1`..`D6` |
| `mjd` | ажиглалтын эхлэл (MJD) |
| `lam_um` | объектын байрлал дээрх долгионы урт (µm). **Frame бүрт өөр** (LVF) — гэрэлтэлтийг зөвхөн ойролцоо `lam_um`-тай frame-үүдийн хооронд харьцуул |
| `noise` | тухайн frame-ийн дэвсгэрийн robust σ (1.4826 × MAD), MJy/sr |
| `nan_frac` | NaN пикселийн хувь (0–1) |
| `epoch` | цагийн бүлгийн дугаар (20 хоногоос их завсраар тасалсан); бүлгүүдийн хураангуй `epochs[]`-д |
| `bg` | хассан дэвсгэрийн түвшин, MJy/sr |

Куб бол **зөвхөн харуулах** зориулалттай: 6.16″ пикселийг 3″ тор руу bilinear-аар шилжүүлсэн тул зэргэлдээ
пикселүүд хамааралтай. Байрлал, урсгалын хэмжилтийг Python түүхий cutout дээр хийнэ (`/api/measure`).

## `measure.json` (урьдчилан тооцоолсон хэмжилт)

Куб бүрийн хажууд `measure.json` бий: кубын төвд байгаа эх үүсвэрийн хөдөлгөөн, `/api/measure`-ийн форматаар
(`python -m data.measure_static`). Кубыг бүтээсэн яг тэр түүхий cutout-ууд дээр хэмжсэн.

- `epochs[]`: epoch бүрийн байрлал ба алдаа; `motion`: `pm_ra`, `pm_dec` (″/жил), `err_ra`, `err_dec`.
- `motion.status`: `"ok"` эсвэл `"unverified"`. **`unverified` бол тоог "хэмжсэн" гэж бүү харуул** — `motion.note`-д шалтгаан бий
  (WISE 0855: нэг зураг дээр хэт бүдэг, зөвхөн shift-and-stack-аар харуулна).
- `saturated: true` бол одны гол ханасан: нэг тэнхлэг найдваргүй, алдаа том гарна (Barnard-ын RA).
- **Параллакс (A-14).** `motion.pm_ra`, `pm_dec` нь каталогийн параллаксыг **тогтмол барьсан** тохируулгын дүн:
  `motion.parallax_arcsec`, `parallax_source` (кубын төвд, зургийн огноонд байгаа Gaia DR3-ийн эх үүсвэр: `catalog.json`-ийн
  `parallax`; олдохгүй бол 0 ба `null` = параллаксгүй шулуун, жишээ нь Gaia-д байхгүй WISE 0855; гараар утга оруулахгүй).
  `motion.no_parallax` = ижил тохируулга параллаксгүйгээр (хуучин дүн). `motion.parallax_fit` = параллаксыг чөлөөт параметр
  болгосон тохируулга (3-аас дээш visit; хэмжиж чадахгүй бол `null`). Зурагт харагдаж буй эх үүсвэр нь зорилтот биш бол
  (WISE 0855-ын D1–D4) параллакс тавихгүй.
- **Детекторууд бие биенээ шалгана.** Нэг объектын `status: "ok"` детекторууд (3-аас дээш) ижил хөдөлгөөнийг хэмждэг. Тэд
  алдааныхаа зурвасаас илүү зөрвөл (жинлэсэн дундаж орчмын chi² > чөлөөний зэрэг) бүгдийнх нь алдааг √(chi²/dof)-оор
  өргөсгөнө: `motion.detector_agreement` (`scale_ra`, `scale_dec`), өргөсгөхөөс өмнөх алдаа `err_ra_fit`, `err_dec_fit`.
  Гаднын каталогийн утгыг энд ашиглахгүй.
- **A-14-ийн дүн (2026-11-15).** Barnard D5: pm_ra −2.83 ± 0.19 (шулуун) → −0.78 ± 0.86 (параллакстай), Gaia −0.80; зургаан детектор бүгд Gaia-г 2σ дотор хамарна.
  Eps Ind B D2: (+3.92 ± 0.12, −2.46 ± 0.11); чөлөөт параллакс таван детектороос 0.303 ± 0.046″ (Gaia 0.271″). Barnard-ын параллакс хэмжигдээгүй
  (0.005 ± 0.261″; 2025-08-ны visit-ийн мөрийн дагуух гажилт, `data/motion.py`-ийн docstring). WISE 0855: параллаксгүй шулуун хэвээр.
- **`motion.json`** (объект бүрт нэг): зургаан детекторын хөдөлгөөн зэрэгцүүлсэн хүснэгт, `combined` (ok детекторуудын
  жинлэсэн дундаж), `parallax_measured` (чөлөөт параллаксын дундаж; алдаа нь детектор хоорондын тархалт /
  √(бие даасан pointing-ийн тоо) — D1/D4, D2/D5, D3/D6 хосууд нэг зэрэг зураг авдаг тул зургаа биш гурав).
- `photometry[]`: зураг бүрийн гэрэлтэлт (`lam_um`, `flux`, `err`, `ok`, `why`, `flags`); `light_curves[]`: ижил долгионы
  (0.02 µm) цэгүүдийн visit-ийн медиан. `photometry_method` = `aperture` (mJy) эсвэл `wing` (MJy/sr, ханасан од) —
  **нэг объектын зургаан детектор бүгд нэг аргаар** (аль нэг детекторт ханадаг бол бүгд `wing`: Barnard, R Dra).
  `photometry_auto_method` нь тухайн детектор дангаараа аль аргыг сонгох байсныг хэлнэ.
- `photometry[].flags`: хэмжсэн пикселүүд дээрх pipeline-ийн flag-ийн нэрс (мэдээллийн SOURCE, FULLSAMPLE-ээс бусад);
  `photometry_flags`: flag тус бүр хэдэн зурагт тохиолдсон. RW Aur D1: 56 зургийн 37-д aperture дотор `OVERFLOW` бий
  (ханалтад ойр) — `photometry_note`-д бичигдсэн, утга нь бага гарсан байж болно.
- **Cosmic ray-ийн дүрэм** (Issue #42, зөвхөн `aperture`): цэг `ok:false` болохын тулд гурван нөхцөл **бүгд** биелнэ —
  (1) хэмжсэн пикселд `TRANSIENT` / `OUTLIER` / `SNOWBALL` / `STREAK` flag; (2) өөрийн visit-ийн бусад цэгийн медианаас 5σ-аас хол;
  (3) долгионы уртаар хамгийн ойр 6 цэгээр (бүх visit) татсан шулуунаас 5σ-аас хол. (3) байхгүй бол жинхэнэ спектрийн
  онцлог хасагдана: eps Ind B 1.2147 µm-д 28.5 mJy (visit-ийн бусад нь 13.9, `TRANSIENT`-тэй) — гэвч өөр дөрвөн visit ижил
  долгионд 24–32 mJy хэмжсэн (T одойн J оргил руу өгсөх хэсэг). Хасагдсан нь нийт 10 цэг: WISE 0855 3 (522.7, 249.2, −1.2 mJy),
  eps Ind B 7 (1387, 1121, 646, 275, 71, 44, 40 mJy). `wing`-д хэрэглэхгүй: ханасан од өөрөө бараг бүх зурагт `TRANSIENT` тавиулдаг
  (R Dra 99%), тэнд flag юу ч ялгахгүй, дүрэм хувьсах одон дээр зүгээр л outlier хасах болно.
- `source_offset_arcsec`: зургуудаас олдсон эх үүсвэрийн медиан байрлал, асуусан байрлалаас (`east`, `north`, `sep`, ″).
  **`sep` > 6.16″ (нэг пиксел) бол олдсон нь зорилтот объект биш** — `motion.status = "unverified"`, шалтгаан `motion.note`-д.

## Зургаан детектор ба `spectrum.json` (A-08)

Таван объект тус бүр D1–D6 бүгдэд кубтай (ижил төв, ижил 61 × 61 тор), нийт 30 куб, 2186 frame, `cube.f32` 32.5 MB
(`flags.u8` 8.1 MB, JSON 2.5 MB нэмэгдэнэ). Дутуу детекторыг `python -m data.fetch_bands` татсан (`data/cache_dr1`,
одоо 2187 файл, 8.2 GB; IRSA 10 хүсэлт тутмын нэгийг 503-аар буцаадаг тул "done, 0 failed" гартал дахин ажиллуул).
Детектор бүрт ≤150 frame (R Dra-ийн D1, D3, D4, D6: 573–584-өөс жигд түүвэр).

| Объект | D1 | D2 | D3 | D4 | D5 | D6 | Арга |
| --- | --- | --- | --- | --- | --- | --- | --- |
| barnard | 60 | 61 | 59 | 59 | 61 | 58 | wing |
| wise0855 | 36 | 48 | 45 | 36 | 48 | 45 | aperture |
| epsindb | 46 | 93 | 96 | 45 | 84 | 93 | aperture |
| rwaur | 56 | 55 | 56 | 56 | 56 | 56 | aperture |
| rdra | 150 | 89 | 150 | 150 | 89 | 150 | wing |

eps Ind B D4: 46 зургийн нэг нь кубд ороогүй — объектын байрлал дээр долгионы урт тодорхойгүй (шүүлтүүрийн ирмэг, flag `DICHROIC`).
Ийм зураг `cube.json`-ийн `skipped[]`-д шалтгаантайгаа бичигдэнэ (`lam_um` нь хэзээ ч `null` биш).

`data/cubes/<obj>/spectrum.json` (`python -m data.measure_static` бүгдийг нэг дор үүсгэнэ):

```
{ object, method, unit, note,
  neighbour: null | { east_arcsec, north_arcsec, sep_arcsec, bands },
  bands:  [{ band, n_images, n_ok, lam_min, lam_max, median_flux, median_snr, n_found, offset_arcsec, detected, why_not }],
  points: [{ band, mjd, epoch, lam_um, flux, err, ok, why }] }      // бүх детектор, долгионы уртаар эрэмбэлсэн
```

- `note`: арга ба нэгж; **детектор хоорондын залгаас дээрх үсрэлтийг засаагүй** (aperture correction байхгүй) гэдгийг хэлнэ.
  Хэрэглэгчид харуул.
- `bands[].detected`: **зорилтот объект** тэр детекторт харагдаж байна уу. Гэрэл байх ёстой (медиан 5 стандарт алдаанаас их,
  эсвэл эх үүсвэр зургуудын талаас илүүд нь олдсон) **бөгөөд** олдсон эх үүсвэр асуусан байрлалаас нэг пиксел дотор байх ёстой.
  Үгүй бол шалтгаан `why_not`-д.
- `neighbour`: aperture (радиус 15″) дотор орсон **өөр эх үүсвэр**.

**WISE 0855: 4 µm-ээс богино долгионд харагдаж байгаа гэрэл WISE 0855 биш.** D1–D4-т aperture-т 1.1 → 0.3 mJy хэмжигддэг,
гэхдээ олдсон эх үүсвэр төвөөс 8.2″ зайд (7.9″ баруун, 2.2″ хойд) бөгөөд хөдөлдөггүй (D2: +0.05 ± 0.11, −0.10 ± 0.40 ″/жил).
Энэ бол Gaia DR3 5756956644387831296 (G = 16.3; CatWISE W2 = 15.20) — каталогийн байрлал (−7.80″, +2.32″), бидний хэмжсэнээс
0.16″ зөрүүтэй. WISE 0855 2025–2026 онд энэ одны хажуугаар өнгөрч байна. Тиймээс `bands[D1..D4].detected = false`,
`neighbour` бөглөгдсөн, `note`-д "values in every detector include its light" гэж бичигдсэн: **D5, D6-гийн утгад ч энэ одны гэрэл орсон**
(хоёрыг салгаагүй; aperture-ийн медиан 3.3–3.8 µm-д 0.30 mJy — зөвхөн од, 4.1–4.8 µm-д 0.67 mJy — од + WISE 0855). D5-д эх үүсвэр хөдөлж байна (−7.85 ± 0.75, +1.31 ± 0.90 ″/жил, `unverified`: нэг зурагт SNR 8)
— WISE 0855-ын каталогийн хөдөлгөөнтэй нийцнэ. Спектрийн графикт D1–D4-ийн цэгийг WISE 0855-ынх гэж бүү харуул.

Бусад үр дүн: eps Ind B бүх детекторт илэрсэн, усны шингээлт тод (медиан 1.25–1.30 µm: 40.6, 1.35–1.40 µm: 6.0, 1.55–1.60 µm: 39.0 mJy);
хөдөлгөөн нь D2–D6 таван детекторт бие даан ижил гарсан (pm_ra +3.43…+3.83, pm_dec −2.20…−2.76 ″/жил). Barnard-ын pm_dec зургаан
детекторт +9.97…+10.46 ″/жил (Gaia +10.36).

## Flag (A-09; `cube.json`, `flags.u8`)

- `flag_names` / `flag_descriptions`: `{ "<bit>": "<нэр>" }` — **файл бүрийн өөрийн `FLAGS` header-ээс** уншсан
  (`MP_<НЭР>` l2b-v20…v25-д, `MSKNnnnn` / `MSKDnnnn` l2b-v27-д; хоёр хэлбэр ижил нэр өгдөг). Жишээ: 0 `TRANSIENT`, 1 `OVERFLOW`,
  2 `SUR_ERROR`, 6 `NONFUNC`, 7 `DICHROIC`, 21 `SOURCE`, 26 `BLOOM`, 27 `SNOWBALL`.
- `flags_informational`: `[12, 21]` (`FULLSAMPLE`, `SOURCE`) — гэмтэл биш, мэдээлэл; `any_frac` ба `flags.u8`-д тооцохгүй.
- `frames[].flags.any_frac`: төвөөс 15″ доторх түүхий пикселүүдийн хэдэн хувь нь гэмтлийн flag-тай; `center_bits`: тэнд тавигдсан
  bit-үүд (мэдээллийнх ч орно). Barnard D1: 60 frame бүгдэд төвд `OVERFLOW`.
- `flags.u8` (`flags_url`): Uint8, `N × H × W`, кубын тор дээр (nearest-neighbour), 1 = тухайн пикселд гэмтлийн flag.
  `cubes_qr/` (нөөц) кубуудад flag байхгүй.

## Хяналтын куб: `wise0855_control/D6` (хоосон тэнгэр)

Хурдны торон хайлт (P-02) олон векторыг туршиж хамгийн тод давхарлалтыг авдаг тул цэвэр шуугиан дээр ч "хамгийн тод" цэг
гарна. Илрүүлэлт утга учиртай байхын тулд ижил хайлтыг хоосон тэнгэр дээр хийж харьцуулна. Энэ куб бол тэр хоосон тэнгэр
(Issue #21; `python -m data.control_cube`).

- **Байрлал:** RA 133.72167, Dec −7.28755 — WISE 0855-аас 215″, байрлалын өнцөг 220° (баруун урд).
- **Ижил exposure:** WISE 0855-ын D6 кубын 45 зураг бүгд (4 epoch), тиймээс шуугиан ба цагийн түүвэрлэлт ижил.
- **Каталогоор (IRSA, 11/14):** төвөөс 46″ дотор W2 < 16.5-тай CatWISE2020 эх үүсвэр байхгүй; 30″ дотор гурав бий
  (W2 = 16.57, 16.91, 17.02 — CatWISE-д WISE 0855 өөрөө W2 = 15.72); 45″ дотор Gaia DR3-ийн хоёр од (G = 19.2, 20.6).
- **Пикселээр:** бүх зургийн медианд төвөөс 30″ доторх хамгийн тод пиксел 3.1σ (WISE 0855-ын кубд ижил хэмжүүр 17.5σ).
- **Анхаар:** 3′ талбай бүхэлдээ хоосон биш — east ирмэгт тод эх үүсвэр бий (CatWISE W2 = 13.78, медианд 37σ).
  "Хоосон" гэдэг нь хайлт хийдэг төвийн 30″-т хамаарна.
- `measure.json`: 45 зургийн 7-д нь шуугианы оргил SNR ≥ 5 шалгуурыг давсан (нэг нь cosmic ray), `motion: null`.
  Өөрөөр хэлбэл хоосон тэнгэрт ганц зургийн "илрүүлэлт" 16% тохиолддог — WISE 0855-ын 45-аас 29 (64%)-тай харьцуулах суурь.

## `catalog.json` (каталогийн эх үүсвэрүүд)

(A-14-өөс: Gaia-ийн эх үүсвэр бүрт `parallax`, arcsec; байхгүй бол `null`. CatWISE-ийн мөрөнд энэ талбар байхгүй.
**Одоогийн файлуудын `parallax` нь ESA-ийн Gaia архиваас** (`gaiadr3.gaia_source`, `source_id`-аар; `source.parallax`-д
тэмдэглэсэн): 2026-11-15-ны шөнө IRSA-ийн TAP унасан (502) байсан. `python -m data.catalog --parallax-from-esa`; бүх эх үүсвэрийн
хөдөлгөөн хоёр архивт 0.02 mas/жил дотор таарсныг шалгаж байж бичдэг. Ердийн `python -m data.catalog` параллаксыг бусадтай нь
хамт IRSA-аас авна.)

Объект бүрийн хавтаст (`data/cubes/<obj>/catalog.json`) кубын төвөөс 150″ доторх Gaia DR3 ба CatWISE2020-ийн эх үүсвэрүүд
(`python -m data.catalog`, IRSA TAP). Формат: `docs/ARCHITECTURE.md` → "Каталогийн давхарга".

- `ra`, `dec` нь `epoch` (жил) дэх байрлал. **Gaia-ийнх 2016.0 оных**, зургууд 2025–2026 оных тул тэмдэглэхээсээ өмнө
  хөдөлгөөнөөр шилжүүл: `dec + pm_dec * (T − epoch) / 3600`, `ra + pm_ra * (T − epoch) / 3600 / cos(dec)`.
  Barnard-ын Gaia-ийн байрлал кубын төвөөс 103″ урд байгаа нь алдаа биш — 10 жилд тэгж хөдөлсөн.
- `pm_ra`, `pm_dec` нь ″/жил (`pm_ra` нь cos(dec)-тэй). `null` бол шилжүүлэхгүй.
- **CatWISE-ийн хөдөлгөөнийг бараг дамжуулдаггүй.** Тод, хурдан одны орчимд CatWISE түүний дүрсний хэсгүүдийг том
  "хөдөлгөөнтэй" тусдаа эх үүсвэр гэж бүртгэдэг (Barnard-ын орчимд 5″/жилээс дээш 14 бүртгэл). Каталогийн өөрийн фитийн
  үзүүлэлт дэмжсэн үед л хөдөлгөөн үлдэнэ: 6 талбарт энэ нь WISE 0855 ба нэг удаан од. eps Ind B-ийн хөдөлгөөн Gaia-д бий.
- **WISE 0855 CatWISE2020-д дөрвөн мөртэй.** Хоёр нь шалгуур давна: (−7.965, +0.806) ба (−7.920, +0.494)″/жил, алдааныхаа дотор ижил.
  Нэгийг нь л үлдээнэ (`rchi2_pm` 1-д ойрыг): `J085508.34-071439.2`, **(−7.965, +0.806)** — апп даяар хэрэглэдэг утга
  (`frontend/lib/objects.ts`: −7.97, +0.81). Spitzer-ийн нарийн хэмжилт: (−8.124, +0.673) (Kirkpatrick нар 2021, ApJS 253, 7).
  Шалгуурт унасан хоёр мөр хөдөлгөөнгүй эх үүсвэр болж файлд үлдсэн. Шалтгаан: `docs/DECISIONS.md` 2026-11-14 19:00.
- R Dra-ийн орчимд CatWISE-д нэг ч эх үүсвэр алга (хэт тод од).
- Нэмэлт талбар `sep_arcsec`: төвөөс (каталогийн epoch дээрх) зай.

## Шалгалтын куб: `teegarden/D1` (A-13)

Хайлтын "тод объектыг нэг гэрэлтэлтэд шилжүүлэх" дүрмийг (A-13, `frontend/search/README.md`) зохиохдоо **ашиглаагүй**
зургаа дахь объект: Teegarden's Star. Сайтын объектын жагсаалтад ороогүй, зөвхөн `frontend/search/numbers.test.ts` уншина.

- **Байрлал:** Gaia DR3 35227046884571776 (2016.0: RA 43.2696425, Dec 16.8643738; хөдөлгөөн +3.429, −3.806″/жил,
  `data.catalog.sources_near`)-ийг 2026.0 руу шилжүүлсэн: RA 43.2795957, Dec 16.8538029.
- **Өгөгдөл:** D1, 55 зураг, 3 epoch (MJD 60889–60895, 61071–61079, 61254–61262). IRSA 56 зураг буцаасны нэг нь
  4 оролдлогод 503 өгсөн тул ороогүй. `python -m data.fetch_field teegarden 43.2795957 16.8538029 D1 --fov 3`, дараа нь
  `python -m data.cube teegarden D1 --cache-dir <data/cache_fov> --out data/cubes/teegarden/D1`.
- `measure.json`, `catalog.json`, `quicklook.png` үүсгээгүй.
